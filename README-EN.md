# 🚆 Safir – Intelligent Train Ticket Automation System
### Safir Automation Engine

---

## 📌 Product Overview

**Safir** is a professional web-based automation system built with **Python (Flask)** that fully automates the process of  
**searching, filtering, reserving, and managing train ticket purchases** from the *Safir Rail* platform.

⚠️ **Important Notice:**  
This project is offered **for sale as a PRIVATE REPOSITORY**.  
The **full source code is NOT public** and is provided **only to the buyer after purchase**.

Safir is designed for **travel agencies, ticket sellers, and advanced users** who need speed, reliability, and full control over the ticket-buying process.

---

## 🎯 Use Cases

- Fast ticket purchasing in high-demand situations  
- Full automation for travel agencies  
- Managing multiple passengers and routes simultaneously  
- Increasing purchase success rate  
- Reducing manual work and human error  

---

## ✨ Key Features

- 🔍 Automatic train ticket search  
- ⏱ Departure time range filtering (from / to hour)  
- 🚆 Train number filtering  
- 🛤 Wagon type filtering (compartment / seat)  
- ⭐ Wagon star rating filtering (3, 4, 5 stars)  
- 👨‍👩‍👧‍👦 Full passenger management  
- 🚪 Private compartment (full coupe) support  
- 🧠 Smart passenger-to-compartment allocation  
- 🔄 Parallel task execution using independent processes  
- 👤 Multiple Safir Rail account management (Account Pool)  
- 🧾 Task management panel (status, edit, retry)  
- 📄 Separate log file for each task  
- 📲 Automatic notifications via:
  - 🤖 Bale Bot  
  - 📩 SMS (Kavenegar)  
- 🧩 Automatic captcha solving (CapMonster)  

---

## 🛠 Technologies Used

- **Backend:** Python, Flask  
- **Database:** SQLite, SQLAlchemy  
- **Frontend:** HTML, CSS, JavaScript (RTL-ready)  
- **Scraping:** Requests, BeautifulSoup  
- **Parallel Processing:** multiprocessing  
- **Migration:** Flask-Migrate  
- **Notifications:** Bale API, Kavenegar SMS  
- **Captcha Solver:** CapMonster
