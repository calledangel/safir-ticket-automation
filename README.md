# 🚆 Safir – سامانه هوشمند خرید و مدیریت بلیت قطار
### Safir Automation Engine

---

## 📌 معرفی محصول

**Safir** یک سامانه تحت وب حرفه‌ای مبتنی بر **Python (Flask)** است که فرآیند  
**جستجو، فیلتر، رزرو و مدیریت خرید بلیت قطار از سامانه سفیر ریل** را به‌صورت کاملاً خودکار انجام می‌دهد.

⚠️ **توجه:** این پروژه به‌صورت **Private Repository** فروخته می‌شود و سورس آن به‌صورت عمومی منتشر نخواهد شد.

این محصول برای **آژانس‌های مسافرتی، فروشندگان بلیت و کاربران حرفه‌ای** طراحی شده و امکان اجرای همزمان چندین تسک خرید، مدیریت اکانت‌ها و ارسال اعلان لحظه‌ای را فراهم می‌کند.

---

## 🎯 کاربردها

- خرید سریع بلیت در شرایط کم‌یابی  
- اتوماسیون خرید برای آژانس‌ها و فروشندگان  
- مدیریت همزمان چند مسافر و چند مسیر  
- کاهش خطای انسانی و افزایش شانس موفقیت  
- کنترل و مانیتورینگ کامل فرآیند خرید  

---

## ✨ امکانات اصلی

- 🔍 جستجوی خودکار بلیت قطار  
- ⏱ فیلتر بازه زمانی حرکت (از ساعت / تا ساعت)  
- 🚆 فیلتر شماره قطار  
- 🛤 فیلتر نوع واگن (کوپه‌ای / سالنی)  
- ⭐ فیلتر ستاره واگن (۳، ۴، ۵ ستاره)  
- 👨‍👩‍👧‍👦 مدیریت کامل اطلاعات مسافران  
- 🚪 پشتیبانی از کوپه دربست  
- 🧠 تشخیص ظرفیت کوپه و تقسیم هوشمند مسافران  
- 🔄 اجرای همزمان چند تسک با Process مستقل  
- 👤 مدیریت چند اکانت سفیر ریل (Account Pool)  
- 🧾 پنل مدیریت تسک‌ها (مشاهده، ویرایش، ری‌تری)  
- 📄 ثبت لاگ مجزا برای هر تسک  
- 📲 ارسال اعلان خودکار:
  - 🤖 Bale Bot  
  - 📩 پیامک (Kavenegar)  
- 🧩 حل خودکار کپچا (CapMonster)  

---

## 🛠 تکنولوژی‌ها

- **Backend:** Python, Flask  
- **Database:** SQLite, SQLAlchemy  
- **Frontend:** HTML, CSS, JavaScript (RTL)  
- **Scraping:** Requests, BeautifulSoup  
- **Parallel Processing:** multiprocessing  
- **Migration:** Flask-Migrate  
- **Notification:** Bale API, Kavenegar SMS  
- **Captcha Solver:** CapMonster
